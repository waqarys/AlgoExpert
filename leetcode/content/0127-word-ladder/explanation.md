# 0127. Word Ladder

**Difficulty:** Hard | **Category:** Graphs | **LeetCode:** https://leetcode.com/problems/word-ladder/

## Problem
- Transform beginWord to endWord changing one letter at a time; every intermediate word must be in wordList. Return the number of words in the shortest sequence, or 0.
- Example: hit -> hot -> dot -> dog -> cog = 5.

## Intuition
- Words are nodes; edges connect words differing by one letter. Shortest path in an unweighted graph = BFS.
- Generate neighbours by trying all 26 letters at each position (L * 26 candidates) instead of comparing with every word.

## Brute Force
- Build the full graph by comparing all word pairs: O(N^2 * L).

## Optimal Approach
1. dict = set(wordList); if endWord missing return 0.
2. BFS from beginWord with level = 1.
3. For each word, for each position and letter: if the candidate is in dict, remove it (marks visited) and enqueue; if it equals endWord return level + 1.

## Worked Example
- hit -> cog, list [hot,dot,dog,lot,log,cog].
```text
level 1: hit
level 2: hot
level 3: dot, lot
level 4: dog, log
level 5: cog -> return 5
```

## Complexity
- Time: O(N * L * 26). Space: O(N * L).

## Pitfalls
- Remove words from the set when enqueued, not when dequeued, to avoid duplicates in the queue.
- Bidirectional BFS is a common follow-up speed-up.

## Video Script
- "Implicit graph + BFS = shortest transformation" - same idea as puzzle solvers.

## Solution
```java file=graphs/WordLadder.java
package graphs;

import java.util.*;

/**
 * LC 127 Word Ladder.
 * Approach: BFS over words; neighbours generated by changing each position to a-z.
 * Time O(N * L * 26), Space O(N * L).
 */
public class WordLadder {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        if (!dict.contains(endWord)) return 0;
        Deque<String> q = new ArrayDeque<>(List.of(beginWord));
        dict.remove(beginWord);
        for (int level = 1; !q.isEmpty(); level++) {
            for (int i = q.size(); i > 0; i--) {
                char[] w = q.poll().toCharArray();
                for (int p = 0; p < w.length; p++) {
                    char orig = w[p];
                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == orig) continue;
                        w[p] = c;
                        String cand = new String(w);
                        if (dict.remove(cand)) {
                            if (cand.equals(endWord)) return level + 1;
                            q.add(cand);
                        }
                    }
                    w[p] = orig;
                }
            }
        }
        return 0;
    }
}
```

package graphs;

import org.junit.jupiter.api.Test;
import java.util.*;
import static org.junit.jupiter.api.Assertions.*;

class WordLadderTest {
    WordLadder s = new WordLadder();
    @Test void examples() {
        assertEquals(5, s.ladderLength("hit", "cog", List.of("hot", "dot", "dog", "lot", "log", "cog")));
        assertEquals(0, s.ladderLength("hit", "cog", List.of("hot", "dot", "dog", "lot", "log")));
        assertEquals(2, s.ladderLength("a", "c", List.of("a", "b", "c")));
    }
}
